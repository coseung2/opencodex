title: Claude Code 대화 이어가기
description: 모델 연결 후 추론 옵션과 도구 실행 뒤 대화가 이어지는지 확인합니다.
---

모델이 목록에 나타나는 것만으로 추론 옵션이나 도구 실행까지 정상 동작한다고 볼 수는 없습니다. 연결을 바꾼 뒤에는 짧은 대화뿐 아니라 파일을 읽고 그 결과로 작업을 계속하는 흐름도 확인하세요.

## 추론 옵션

연결된 모델의 지원 강도와 겹치는 기존 기본 모델의 메뉴를 사용합니다. 지원 정보가 없는 모델에 임의로 추론 옵션을 만들지는 않습니다. CLI의 `cc` 카탈로그와 대체 bootstrap 목록은 Desktop의 `ccd`·`code` 목록과 별개입니다.

메뉴가 예전 상태라면 새 Claude Code 세션에서 모델 카탈로그를 갱신하세요. CLI 카탈로그 캐시는 앱 재시작 뒤에도 남을 수 있으므로, 예전 목록만으로 현재 설정을 판단하지 마세요.

## 도구와 스킬 실행 뒤 작업 계속하기

ToolSearch 결과의 도구 이름을 보존하며, 함수 도구의 선택 매개변수를 임의로 필수 매개변수로 바꾸지 않습니다.

연결된 모델에서는 기본적으로 큰 `claude-api` 참고 자료 묶음을 생략합니다. Skill 도구에 예방 안내를 전달하고, 그래도 실행된 경우 기본 인사로 돌아가지 말고 기존 작업을 계속하도록 안내합니다. 자료를 유지하려는 경우에만 `claudeCode.blockedSkills`를 빈 배열로 설정하세요.

Responses 모델의 숨겨진 추론은 화면에 노출하지 않고 다음 턴으로 전달할 수 있습니다. 실제 요청 주소·모델·인증 정보가 일치하는지 검증하며, 연결이나 인증이 바뀌거나 프록시가 재시작되면 해당 내부 상태는 재사용하지 않습니다. 화면에 보이는 대화 이력은 유지됩니다. 다른 제공자의 내부 상태를 기본 Anthropic 대화에 보내지 않습니다.
